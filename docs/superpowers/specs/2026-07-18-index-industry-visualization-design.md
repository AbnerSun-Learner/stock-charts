# 行业分类可视化优化设计

## 目标与范围

将指数仪表盘的行业权重区域升级为参考图风格的“环形占比图 + Top 3 结构观察卡”，同时保留申万一/二/三级切换和完整明细表。只使用现有 `index_industry_weights` 数据，不新增或虚构代表公司、行业点评和数据来源字段。

## 布局与视觉

- 桌面端采用 7:5 双栏：左侧环形图与图例，右侧结构观察卡；移动端纵向堆叠。
- 环形图使用稳定的高区分度色板，标签展示行业名与百分比，中心展示当前申万级别和“行业暴露”。
- 图表最多展示前 15 个行业，其余继续合并为“其他”，避免申万三级标签拥挤。
- 观察卡展示当前级别权重最高的三个行业、各自权重、前三合计集中度和权重日期。
- 完整明细表置于双栏下方，继续支持分页。
- loading、empty、tooltip 和主题颜色沿用现有页面 CSS 变量，不复制参考图中的品牌内容。

## 数据与交互

- Tabs 切换后，环形图、Top 3、集中度和明细表同步更新。
- 新增纯函数 `summarizeIndustryConcentration(weights, topN)`，按权重降序返回 Top N 与合计权重，供观察卡使用并由 Jest 覆盖。
- 图表沿用动态导入，避免恢复已修复的首屏包体积问题。

## 验证

- 单测覆盖 Top 3 排序、合计权重、空数组和非法 `topN`。
- 生产构建成功，指数仪表盘 First Load JS 仍小于修复前的 784 kB。
- Playwright 验证行业权重标题、结构观察、前三集中度和明细表在真实数据下可见。
- 使用浏览器截图检查桌面端与移动端布局、标签可读性和溢出。
