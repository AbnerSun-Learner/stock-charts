# 家庭财务总览 · 资产结构桑基图

**日期**：2026-07-23  
**状态**：已实现（2026-07-23）  
**相关**：[家庭财务总览设计](./2026-07-22-family-finance-overview-design.md)、[Ant Design Charts Sankey](https://ant-design-charts.antgroup.com/examples/statistics/sankey/#alipay)

## 目标

删除总览「成员分布」饼图，替换为桑基图，表达：

`负债条目 + 净资产 → 总资产 → 四笔钱 → 资产条目`

## 非目标

- 不改记账 / 保单 CRUD 语义
- 不按成员再拆中间层
- 不自绘 SVG Sankey

## 产品决策

| 项           | 选择                                   |
| ------------ | -------------------------------------- |
| 中间层       | 活钱 / 稳钱 / 长钱 / 保险（资金标签）  |
| 标签         | 均含金额：`名称 · … · formatCny(金额)` |
| 无四笔钱标注 | 静默跳过（记账侧资产四笔钱必填）       |
| 净资产 ≤ 0   | 不画「净资产 → 总资产」边              |
| 布局         | KPI → 桑基全宽 → 心理账户 \| 保单 并排 |

## 数据流

```
负债条目(i) →「负债 · ¥L」→「总资产 · ¥A」→「活钱 · ¥…」→ 资产条目
「净资产 · ¥N」─────────────↗              →「稳钱 · ¥…」→ …
                                              →「长钱 · ¥…」→ …
                                              →「保险 · ¥…」→ …
```

其中 `A = 资产合计`，`L = 负债合计`，`N = A − L`（仅 N>0 时连净资产边）。

1. 总览不再显示成员分布饼图
2. 桑基全宽，流向符合上表
3. 节点标签含金额

5. 无标注资产时桑基 Empty
