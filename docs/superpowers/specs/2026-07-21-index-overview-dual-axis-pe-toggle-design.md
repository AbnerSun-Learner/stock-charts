# 指数走势双轴与市盈率显隐开关设计

## 背景与目标

参考 [ETF.run 沪深 300 指数页](https://www.etf.run/index/SSE/000300) 的走势图交互：收盘与市盈率双轴叠画，并由「市盈率」区块的滑动开关控制 PE 折线显隐。本仓继续只读 `index_daily_metrics`，不抓取 ETF.run 数据。

## 范围

### 纳入范围

- 指数走势图改为双轴：左 Y 市盈率、右 Y 收盘点位（刻度单位 `K`）。
- 右侧「市盈率 PE_TTM」面板标题栏增加 `Switch`，控制走势图中 PE 系列显隐。
- 默认关闭；开启后显示 PE 线与左轴，关闭后仅保留点位线与右轴。
- `pe_ttm` 为空的交易日不画 PE 点；当前窗口整段无 PE 时开关 `disabled`。

### 不纳入范围

- 市净率开关、极限跌幅水位线叠画。
- PE/PB 历史均值虚线叠画。
- 开关状态 URL / localStorage 持久化。
- 补全其他指数的 `index_daily_metrics` 历史（属 `scheduled-tasks`）。

### Tooltip（hover）

开启市盈率且当日有 PE 时，展示参考站风格分组文案：

- 标题：指数名 + 短代码、日期
- 收盘：收盘价、历史累计涨跌、距前高下跌
- 市盈率：市盈率、历史分位、五年/十年分位
- 五年/十年均值与现值偏离

关闭市盈率或当日无 PE 时，仅展示收盘分组。涨跌着色遵循 A 股习惯（涨红跌绿）。字段均由窗口内 `close` / `pe_ttm` 推算，不依赖快照表。

## 数据支持度（2026-07-21 实查）

结论：**部分足够**，可实现，需接受稀疏与标的缺口。

| 维度               | 结论                                                                  |
| ------------------ | --------------------------------------------------------------------- |
| 表字段             | `index_daily_metrics.close` / `pe_ttm` / `pb` 已存在；Repository 已读 |
| 标的               | 当前仅 `000300.SH` 有日序；池内其余指数可能空态                       |
| 收盘跨度           | `2002-01-04`–`2026-07-20`                                             |
| PE 跨度            | `2016-07-18`–`2026-07-20`（约占收盘行 40.8%）                         |
| 近 5 年 / 近 10 年 | 窗口内 close 与 pe_ttm 行数对齐，可完整叠画                           |
| 上市以来           | 2016 前仅有点位；开启 PE 后折线仅出现在后半段（正常降级）             |

## 交互与布局

本页为左右双栏：左「指数走势」，右「市盈率」等估值面板。开关放在右侧市盈率面板标题栏（`PanelShell.action`），与 ETF.run 区块归属一致，不放在走势图标题栏。

状态提升到 `IndexDashboardPage`：`showPeLine` 默认 `false`，下传给 `ValuationPanel`（仅 `peTtm`）与 `IndexOverviewPanel`。

## 图表行为

- 使用 `@ant-design/charts` 的 `DualAxes`（`dynamic` + `ssr: false`）。
- 右轴：收盘点位，刻度统一格式化为 `K`（如 `3.4K`）。
- 左轴与 PE 线：仅 `showPeLine === true` 时渲染。
- 整段无有效 `peTtm` 时：Switch `disabled`，不单独弹额外空提示（估值面板本身已有空态）。
- Tooltip：开启时展示收盘 + 市盈率；关闭时仅收盘。
- 时间窗口（`all` / `10y` / `5y`）仍过滤同一份 `visibleMetrics`。

## 组件职责

| 组件                 | 职责                                                                     |
| -------------------- | ------------------------------------------------------------------------ |
| `IndexDashboardPage` | 持有 `showPeLine`；判断当前窗口是否存在任一有效 `peTtm` 以决定开关可用性 |
| `ValuationPanel`     | `metric === 'peTtm'` 时渲染 Switch；`aria-label="显示市盈率折线"`        |
| `IndexOverviewPanel` | 按 `showPeLine` 配置 DualAxes 系列与轴                                   |

不新增表、不新增 Repository 方法；沿用 `IndexMetricPoint.close` / `peTtm`。

## 测试要点

- 单元：双轴数据映射在 `showPeLine` 开关下包含/排除 PE 系列；空 `peTtm` 被过滤。
- 组件/E2E：默认无 PE 线；打开市盈率开关后出现 PE 系列（可用 mock 路由）。

## 验收标准

1. 默认进入页面：走势图仅点位线，右轴为 K 单位，市盈率开关为关。
2. 打开开关：出现 PE 折线与左轴；tooltip 含市盈率。
3. 关闭开关：PE 线与左轴消失，点位线保留。
4. 「上市以来」开启 PE 时，早期无 PE 区间不断线报错、不造假数。
5. 无 PE 数据的指数：市盈率开关 `disabled`，页面不崩溃。
