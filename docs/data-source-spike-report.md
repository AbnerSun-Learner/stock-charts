# 数据源 Spike 报告（Phase 2）

> 验收日期：2026-07-03  
> 目的：对比免费行情/估值源可用性，为 API Route 主备降级提供依据。  
> 说明：以下结论基于开发环境抽样请求与公开文档，**不代表第三方接口稳定性承诺**。

## 1. 候选源对比

| 维度 | 东方财富（主源） | 新浪财经（备源） | 腾讯财经（未接入） |
| --- | --- | --- | --- |
| **可用字段** | K 线 OHLCV+成交额；指数 PE/PB/股息率历史 | K 线 OHLCV（无成交额） | 实时报价、部分 K 线 |
| **历史深度** | K 线可回溯多年；指数估值约 10 年+ | K 线约 1023 根（~4 年） | 未实测 |
| **平均延迟** | ~200–600 ms | ~300–800 ms | 未实测 |
| **P95 延迟** | ~1.2 s（偶发） | ~1.5 s | 未实测 |
| **限流** | 高频请求可能 403/空包；需 User-Agent | 较宽松，但字段少 | 未实测 |
| **字段稳定性** | JSON 结构较稳定；偶发 `klines` 空数组 | 数组 JSON，字段名固定 | 未实测 |
| **合规风险** | 非官方 API，需低频 + 服务端缓存 | 同上 | 同上 |
| **降级策略** | 主源 → 新浪 K 线；估值暂无独立备源 | 作为 K 线备源 | 后续可评估 |

## 2. 已接入接口

| Route | 主源 | 备源 | 缓存 TTL |
| --- | --- | --- | --- |
| `GET /api/market/etf-kline` | `push2his.eastmoney.com` | 新浪 `getKLineData` | 24 h |
| `GET /api/market/index-valuation` | `datacenter-web.eastmoney.com` | 无（仅 24h 缓存 + stale 兜底） | 24 h |

统一响应字段：`source`、`timestamp`、`stale`、`fallbackUsed`、`warnings`。

## 3. 字段覆盖与指标依赖

| 指标 | 东方财富 | 新浪 | 缺口 |
| --- | --- | --- | --- |
| ATR20% | ✅ high/low/close | ✅ | 备源无 amount |
| 90/250 日相关 | ✅ close 序列 | ✅ | 备源历史较短 |
| 估值百分位 | ✅ PE/PB/股息率 | ❌ | 需备源或缓存 |
| 日均成交额 | ✅ amount | ❌ | 备源降级为 unknown |
| IOPV/溢价 | ❌ 未接入 | ❌ | Phase 3+ |

## 4. 风险与后续

1. **估值备源**：Spike 未找到可用独立备源；当前仅东方财富单源，降级依赖 24h 缓存 + stale；生产前应接入中证指数或第二免费源并单独 spike。
2. **限流**：所有请求经 Next.js API Route 代理，日频数据 24h 缓存；禁止前端直连。
3. **历史深度**：新浪 K 线 `datalen=1023` 限制 250 日长期相关时需优先主源。
4. **合规**：仅用于个人投研工具，低频缓存，不做商业化分发。

## 5. Spike 结论与 Phase 2 验收映射

| 链路 | provider 主备 | 缓存 + stale 兜底 | Phase 2 可宣称 |
| --- | --- | --- | --- |
| K 线（`etf-kline`） | ✅ 东财 → 新浪 | ✅ 24h | 完整降级 |
| 估值（`index-valuation`） | ❌ 仅东财单源 | ✅ 24h | **仅缓存兜底**，非 provider 降级 |

- ✅ K 线：东方财富 + 新浪双源可满足 Phase 2 **provider 降级**验收。
- ⚠️ 估值：仅东方财富单源，**不满足 provider 降级验收**；依赖 24h 缓存 + stale 提示，全失败时 503。Phase 2 可标为「单源 + 缓存兜底完成」，不可标为「主备降级完成」。
- ⏭️ 份额/IOPV/实时报价：留待 Phase 3–4 单独 spike。
